GeekDown

Date: April 12, 2025

GeekDown is a markdown editor I started working on, partly to familiarize myself more with Milkdown, which I plan on using in FearlessCMS. Markdown is a language that's popular with notetaking but is also used in various documents and content management systems on the world wide web. Markdown is even used on Github.

Features

  • Markdown Editing: Full markdown syntax support
  • Milkdown Integration: Built on the powerful Milkdown editor framework
  • Template System: Create and use custom templates
  • Template Tester: Test templates before using them
  • Template Submission: Submit new templates to the community

Technology Stack

  • Frontend: React, TypeScript
  • Editor: Milkdown
  • Styling: Tailwind CSS
  • Build Tool: Vite

Project Status

Currently in active development. The editor is functional with basic markdown editing capabilities and template management.
