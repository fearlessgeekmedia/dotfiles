# Fearless Geek Media Theme

A professional web design and development theme with a terminal aesthetic, built for FearlessCMS.

## Features

- **Terminal Aesthetic**: Uses Fira Mono font for a developer-friendly look
- **Responsive Design**: Mobile-first approach with hamburger menu
- **Dark Mode**: Built-in dark color scheme
- **Blog Support**: Optimized for blog content display
- **Projects Support**: Grid layout for portfolio projects
- **Social Integration**: Built-in social media links
- **TypeIt Animation**: Animated typing effect for the main header

## Color Scheme

- **Primary**: #00c767 (Green)
- **Secondary**: #02a002 (Dark Green)
- **Accent**: #80aadd (Blue)
- **Background**: #252627 (Dark Gray)
- **Text**: #999 (Light Gray)
- **Header**: #252627 (Dark Gray)

## Fonts

- **Monospace**: Fira Mono (for headings and terminal elements)
- **Sans-serif**: Open Sans (for body text)

## Templates

- `base.html` - Base template with header, navigation, and footer
- `home.html` - Homepage with hero section and social links
- `about.html` - About page template
- `projects.html` - Projects/portfolio template
- `blog.html` - Blog listing template
- `discovery-session.html` - Discovery session page
- `page.html` - Generic page template

## Usage

1. Copy this theme to your FearlessCMS themes directory
2. Set it as the active theme in your CMS configuration
3. Customize the content and social media links as needed

## Customization

The theme uses CSS custom properties for easy color customization. You can modify the colors in the `:root` section of the CSS file.
